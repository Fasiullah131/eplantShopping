# eplantShopping

## Description
eplantShopping is a React e-commerce application for buying plants online.

## Features
- Browse plant catalog with 3 categories: Indoor, Succulent, Flowering
- Add items to shopping cart
- Update quantity and remove items from cart
- Calculate total price automatically

## Tech Stack
React, Redux Toolkit, CSS

## How to Run
1. npm install
2. npm start
